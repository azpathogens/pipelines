# Requirements for Pipelines for Use with APGAP Projects

Do you have a pipeline that you would like to have included in our GitHub organization to encourage reuse of your pipeline? We would love to include it! We just have a few requirements for your repository to ensure other users can easily use your pipeline.

## Prerequisites

* [ ] **Repository Description:** A clear, concise summary to be present in the repository's **About** section on GitHub. This description will be shown on APGAP's pipeline page, so make sure it tells users for what they can use your pipeline.
* [ ] **License:** The repository must contain an official license file (`LICENSE` or `LICENSE.md`) in the root directory containing an open source license (e.g., MIT, Apache 2.0). Unlicensed repositories cannot be used by others!
* [ ] **Contact Information:** Make sure to include in your `README.md` file how users can report issues or ask questions.
* [ ] **Documentation:** Please make sure your `README.md` file has enough documentation so other people can use your pipeline.

## Questions?

Do you have any questions? Please [open an issue](https://github.com/azpathogens/pipelines/issues/new/choose) in this repository or get in touch with us through the official [APGAP website](https://azpathogens.org/).
